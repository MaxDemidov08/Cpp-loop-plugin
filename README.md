## Описание проекта
**Smart C++ Loop Inserter** — это программное расширение (плагин) для среды разработки Visual Studio Code, написанное на **TypeScript**. 

Плагин предназначен для интеллектуальной автоматизации написания рутинных конструкций (циклов `for`) в языке C++. В отличие от стандартных статичных сниппетов (заготовок текста), данный плагин выполняет динамический контекстный анализ открытого документа, считывает объявленные выше структуры данных (контейнеры) и генерирует код цикла индивидуально под переменные пользователя.

### Основные возможности:
* **Контекстный анализ кода:** Сканирует документ вверх от курсора на глубину до 50 строк.
* **Распознавание контейнеров:** Автоматически находит векторы (`std::vector<T>` / `vector<T>`) любой вложенности, а также классические статические массивы C++ (`type name[size]`).
* **Автоопределение типов:** Парсит типы данных внутри контейнера с помощью регулярных выражений и подставляет их в цикл (например, `const int&`, `const std::string&`).

### Основные методы и функции:
    | :---: | :---: |
    | *Метод* | *Описание* |
    | **`foreach`:** | Генерирует современный синтаксис `for (const Type& item : container)`.|
    | **`foreach`:** | Определяет тип контейнера и автоматически подставляет метод `.size()` для векторов или оставляет изменяемый фокус для размера обычного массива. |
