## Описание плагина
**Smart Loops** — это контекстно-зависимый плагин автодополнения для среды разработки **Visual Studio Code**, ориентированный на язык **C++**. 

В отличие от стандартных статических сниппетов, данный плагин динамически анализирует контекст написанного кода (до 50 строк вверх от курсора) с помощью регулярных выражений, определяет объявленные контейнеры данных и генерирует циклы со строго типизированными переменными и автоматическим вычислением размера.

### Основные возможности:
1. **Умный Range-based цикл (`for_each`):** Находит объявления `std::vector<T>` или `Array<T>`, извлекает тип данных элемента и имя контейнера, формируя цикл вида `for (const Type item : containerName)`.
2. **Индексный цикл со счетчиком (`for_index`):** Автоматически определяет, поддерживает ли контейнер метод `.size()` (для `std::vector`), и подставляет его в условие завершения цикла.

## Техническое задание (ТЗ)
* **Целевая IDE:** Visual Studio Code.
* **Язык разработки плагина:** TypeScript / JavaScript.
* **Входные данные:** Позиция курсора пользователя, текст текущего открытого документа (`.cpp`).
* **Логика работы:** 
  * Поиск объявлений контейнеров методами Regex.
  * Выделение названия и типа сущности.
  * Формирование динамических объектов `vscode.CompletionItem`.
* **Требования к коду:** Наличие алгоритмической логики поиска и фильтрации данных (простая подстановка сниппетов не допускается).
