# Документация проекта: Архитектура и Логика плагина

## 1. Архитектура интеграции с IDE
Visual Studio Code изолирует выполнение плагинов в отдельном процессе — **Extension Host**. Это предотвращает падение или зависание редактора при ошибках в коде расширений. 

Наш плагин взаимодействует с ядром через публичное API `vscode`, регистрируя новый провайдер автодополнения с помощью метода `vscode.languages.registerCompletionItemProvider`. 

### Схема взаимодействия компонентов:
1. **Событие:** Пользователь вводит символы в файле со спецификатором языка `cpp`.
2. **Активация:** VS Code вызывает метод `provideCompletionItems` нашего плагина.
3. **Анализ:** Плагин запрашивает объект `TextDocument`, считывая текстовые строки.
4. **Результат:** Плагин возвращает массив объектов `vscode.CompletionItem[]`, которые IDE рендерит в выпадающем списке подсказок Intellisense.
